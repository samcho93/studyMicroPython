# 🧑‍🏫 교사용 수업 운영 안내

마이크로비트 MicroPython 웹 실습 강좌를 학교 수업에서 쓰는 방법을 정리했습니다.

---

## 1. 준비하기

### 반드시 필요한 것

- **학생용 PC · 태블릿** (브라우저만 있으면 됩니다)
- 인터넷 연결 — 처음 실행할 때 파이썬 실행 환경(Pyodide)을 내려받습니다

### 있으면 좋은 것

| 준비물 | 쓰는 곳 | 비고 |
|---|---|---|
| BBC micro:bit **V2** | 전 과정 | V1 도 대부분 동작 (12장 마이크·효과음 제외) |
| **데이터용** USB 케이블 | 보드 연결 | 충전 전용 케이블은 동작하지 않습니다 |
| AA 건전지 팩 | 1장, 14장 | USB 없이 동작 확인 |
| 악어클립 (10개 이상) | 5장, 13장, 14장 | 큰 단자 연결용 |
| LED + 220Ω 저항 | 5장 | 조별 3~5세트 |
| 택트 스위치 · 토글 스위치 | 5장 | |
| 가변저항 (10kΩ) | 5장, 6장 | |
| 부저 · 이어폰 | 6장, 12장 | V1 은 필수 |
| 서보 모터 (SG90) | 5장, 14장 | 별도 전원 권장 |
| NeoPixel 띠 (8~16개) | 14장 | |
| 자석 · 이어폰 | 10장 | 금속 탐지 실습 |

> **보드가 없어도 모든 실습이 가능합니다.** 시뮬레이터의 🧩 부품 탭에서 LED · 버튼 ·
> 가변저항 · 부저 · 서보 · NeoPixel 을 연결해 똑같이 실습할 수 있습니다.

### 수업 전 점검

1. 교사 PC 에서 강좌를 열고 **▶ 실행**이 되는지 확인 (첫 실행은 5~20초 소요)
2. 학생 PC 의 **소리**가 나는지 확인 (6장, 12장에 필요)
3. 보드를 쓸 경우 **python.microbit.org** 에서 MicroPython 펌웨어를 미리 설치
4. 교실 LAN 만 쓴다면 `python server/serve.py --lan` 으로 교사 PC 에서 배포

## 2. 화면 사용법

### 교사용 / 학생용

| | 🎓 학생용 | 🧑‍🏫 교사용 |
|---|---|---|
| 주소 | `student.html` | `teacher.html` |
| 기본 화면 | 문서형 강좌 | 16:9 슬라이드 |
| 추가로 보이는 것 | — | 교사 노트, 수업 흐름(시간 배분), 퀴즈 정답, 실습 정답 코드 |

좌측 상단의 **🎓 학생용 / 🧑‍🏫 교사용** 버튼으로 언제든 전환할 수 있습니다.
전환하면 그 역할의 기본 화면(학생용=문서, 교사용=슬라이드)으로 시작합니다.

> **교사용 비밀번호** — 정답과 교사 노트가 학생에게 바로 보이지 않도록
> 교사용으로 들어갈 때 비밀번호를 한 번 묻습니다. **기본값은 `microbit`** 이고,
> 한 번 확인하면 그 브라우저에서는 다시 묻지 않습니다.
> 바꾸려면 `js/app.js` 맨 위의 `TEACHER_PASS` 값을 고치세요.
> 모든 판단이 브라우저 안에서 이루어지므로 **보안 수단이 아니라 가림막**입니다.

### 슬라이드 화면 — 상단 메뉴

슬라이드는 **16:9(1280 × 720) 고정 무대**를 화면 크기에 맞춰 축소·확대합니다.
상단 메뉴는 두 줄이고, 둘째 줄(판서)은 교사용에서만 보입니다.

**첫째 줄 — 이동과 보기**

| 버튼 | 하는 일 |
|---|---|
| `⏮ 처음` | 첫 슬라이드로 (<kbd>Home</kbd>) |
| `◀` `▶` | 이전 · 다음 슬라이드 |
| `6 / 25` | 현재 쪽 / 전체 쪽수 |
| 페이지 슬라이더 | 끌어서 원하는 쪽으로 바로 이동 |
| 슬라이드 제목 | 지금 보고 있는 슬라이드 이름 |
| `⏱ 00:00` `↺` | 수업 타이머(눌러서 시작/일시정지) · 초기화 |
| `🗒 발표자 창` | 노트 · 다음 슬라이드 · 타이머가 보이는 별도 창 |
| `▦ 목록` | 전체 슬라이드 목록에서 골라 이동 |
| `📄 문서` | 스크롤 문서 보기로 전환 |
| `⛶ 전체 화면` | 전체 화면 발표 |

맨 아래 가는 막대가 진행률입니다. 전체 화면 중에는 상단 메뉴가 숨고,
**마우스를 화면 맨 위로 올리면** 다시 내려옵니다.

**둘째 줄 — ✏️ 판서 (교사용 전용)**

- 도구 : `🖊 펜` · `🖍 형광펜`(반투명·굵게) · `🧽 지우개`(스친 획을 통째로 삭제) · `👆 지시봉`(가리키기만)
- 색 6가지 / 굵기 3단계(가늘게 · 보통 · 굵게)
- `↶ 되돌리기`(<kbd>Ctrl</kbd>+<kbd>Z</kbd>, 50단계) · `🗑 이 장 지우기` · `🗑 모두`
- 지우개·지시봉 상태에서 색이나 굵기를 고르면 **자동으로 펜으로 돌아갑니다**
- 판서는 **슬라이드마다 따로 보관**되어 다음 장에 갔다 와도 남아 있고, 화면 크기에 따라 같이 커집니다.
  새로 고치면 지워지고, 고른 도구·색·굵기만 기억합니다.

### 슬라이드 위에서 마우스로

- **좌우 가장자리**(슬라이드 너비의 6%, 최소 28px)를 클릭하면 이전 · 다음 쪽.
  마우스를 올리면 옅은 띠와 `‹` `›` 가 보입니다.
- **가운데**는 지시봉 커서입니다. 여기서 **누른 채 끌면 판서**가 됩니다.
  끌지 않은 단순 클릭으로는 점이 찍히지 않고, 그리기를 끝낸 클릭으로 쪽이 넘어가지도 않습니다.
- 버튼 · 링크 · 퀴즈 보기 · 코드 편집기 위에서는 평소대로 눌리고 쪽이 넘어가지 않습니다.

### 전체 화면 발표 중 결과 창

- 평소 화면에서는 오른쪽 결과 창(시뮬레이터 · 콘솔)이 항상 보입니다.
- **전체 화면에서는 숨어 있다가 코드를 실행하면 열립니다.**
  결과 창 머리의 `✕` 또는 <kbd>R</kbd> 로 닫고, 슬라이드를 넘기면 다시 닫힌 채로 시작합니다.
- 시뮬레이터 머리의 `⤢ 크게 보기` 는 발표 중에도 열립니다.
  열려 있을 때 <kbd>Esc</kbd> 는 크게 보기만 닫고 발표 화면은 그대로 둡니다.

### 슬라이드 단축키 (교사용)

| 키 | 동작 |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> <kbd>Space</kbd> | 이전 · 다음 슬라이드 |
| <kbd>Home</kbd> <kbd>End</kbd> | 첫 · 마지막 슬라이드 |
| <kbd>F</kbd> | 전체 화면 |
| <kbd>G</kbd> | 슬라이드 목록 |
| <kbd>R</kbd> | 결과 창 열기/닫기 |
| <kbd>N</kbd> | 교사 노트 열기/닫기 |
| <kbd>B</kbd> | 화면 가리기 (학생 주목시킬 때) |
| <kbd>T</kbd> | 수업 타이머 시작/일시정지 |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 판서 되돌리기 |
| <kbd>Esc</kbd> | 닫기 · 전체 화면 종료 |

**🗒 발표자 창**을 누르면 두 번째 창이 열립니다. 빔프로젝터에 전체 화면을,
교사 노트북에 발표자 창(노트 + 다음 슬라이드)을 띄워 두면 편합니다.

### 교사용 노트 (슬라이드 아래)

제목줄에 `🗒 교사용 노트`, 오른쪽에 다음 슬라이드 제목과 `▾ 접기` 버튼이 있습니다.
제목줄이나 버튼을 누르면 한 줄로 접히고 그만큼 슬라이드가 커집니다. 접은 상태는 기억됩니다.

### 슬라이드 위치 기억

주소는 `#강의id@쪽번호` 형식입니다(예: `#ch03-1@4`). 같은 강의를 새로 고치거나
보기 방식을 바꿀 때는 보던 쪽에서 이어지고, **다른 강의로 옮기면 언제나 1쪽부터** 시작합니다.

### 시뮬레이터 조작

- 보드 그림의 **A · B 버튼**: 마우스로 누르기, 키보드 <kbd>A</kbd> <kbd>B</kbd> 도 가능
- 금색 **로고**, 아래쪽 큰 단자 **0 · 1 · 2**: 눌러서 터치
- **🧭 센서**: 기울기 판 드래그, 제스처 버튼, 온도 · 빛 · 소리 · 방위각 슬라이더
- **🔌 핀**: 핀별 모드 · 값 확인, 입력을 0/1 로 강제
- **🧩 부품**: LED · 버튼 · 가변저항 · 부저 · 서보 · NeoPixel 연결
- **📡 무선**: 가상 짝 보드 설정, 수신함에 메시지 넣기
- **💾 파일**: 프로그램이 만든 파일 보기 · 삭제
- **📊 로그**: `log` 모듈 기록을 표로 보고 CSV 내려받기

## 4. 수업 진행 요령

### 예제 다루기

1. **먼저 실행해 보여 줍니다.** 결과를 본 뒤 코드를 설명하면 집중도가 다릅니다.
2. **학생이 직접 입력하게 합니다.** 복사 붙여넣기보다 오래 기억합니다.
3. **숫자를 바꿔 보게 합니다.** `sleep(1000)` → `sleep(100)`, `delay=150` → `delay=500`.
   "왜 그럴까?" 를 스스로 발견하는 것이 핵심입니다.
4. **일부러 틀린 코드를 보여 줍니다.** 오류 메시지를 함께 읽는 경험이 중요합니다.

### 자주 나오는 실수

| 증상 | 원인 | 지도 |
|---|---|---|
| `NameError: name 'display'…` | `from microbit import *` 누락 | 첫 줄 확인 습관 |
| `SyntaxError: invalid character` | 한글 따옴표 `“ ”` | 영문 자판으로 직접 입력 |
| `IndentationError` | 들여쓰기 | 공백 4칸, 탭과 섞지 않기 |
| 1초인데 너무 빠름 | `sleep(1)` | **밀리초** 단위 (1초 = 1000) |
| 버튼을 한 번 눌렀는데 여러 번 | `is_pressed()` 사용 | `was_pressed()` 로 |
| NeoPixel 이 안 켜짐 | `np.show()` 누락 | 색 지정 후 반드시 show() |
| 나침반이 이상함 | 보정 안 함 | `compass.calibrate()` 먼저 |
| radio 오류 | `radio.on()` 누락 | 켜기 먼저 |

### 안전 지도 (5장 · 14장)

- micro:bit 핀 하나는 **약 5mA**, 3V 단자 전체는 **약 90mA** 까지만 낼 수 있습니다.
- **LED 에는 반드시 저항**(220Ω 정도)을 함께 연결합니다.
- 모터 · NeoPixel 을 많이 쓸 때는 **별도 전원 + 공통 GND**.
- 두 보드를 전선으로 이을 때는 **GND 를 반드시 연결**합니다.

## 6. 교실 환경별 안내

### 인터넷이 느리거나 없는 교실

- 처음 한 번은 인터넷이 필요합니다 (Pyodide 내려받기, 약 10MB).
- 이후에는 브라우저 캐시로 동작하지만, 캐시를 지우면 다시 받아야 합니다.
- 교사 PC 에서 `python server/serve.py --lan` 으로 강좌 파일만 배포할 수 있습니다.
  (파이썬 실행 환경은 여전히 인터넷에서 받아옵니다)

### 보드가 모자랄 때

- **시뮬레이터로 개별 실습 → 보드로 조별 확인** 방식이 효율적입니다.
- 13장 radio 는 조별로 2대씩 있으면 충분합니다.

### 브라우저

- **Chrome · Edge** 권장 (실제 보드 연결에 필요한 Web Serial 지원)
- Firefox · Safari 는 시뮬레이터만 사용 가능
- 태블릿 · 모바일도 시뮬레이터 실습은 가능하지만 화면이 좁습니다

## 7. 자주 묻는 질문

**Q. 학생이 작성한 코드는 저장되나요?**
A. 브라우저에 교시별로 자동 저장됩니다. 다른 PC 에서는 이어지지 않으므로,
중요한 코드는 `💾` 로 `main.py` 파일로 저장하게 하세요.

**Q. 진도 기록을 초기화하려면?**
A. 브라우저의 사이트 데이터를 지우면 초기화됩니다.

**Q. 실제 보드에서 코드가 다르게 동작합니다.**
A. 메모리(약 128KB)와 속도가 시뮬레이터보다 훨씬 제한적입니다.
긴 프로그램은 `MemoryError` 가 날 수 있으니 주석을 줄이거나 코드를 나누세요.

**Q. V1 과 V2 의 차이는?**
A. V1 에는 스피커 · 마이크 · 터치 로고가 없습니다.
6장(음악)은 P0 에 이어폰을 연결하면 되고, 12장의 `audio` · `microphone` 은 V2 전용입니다.

**Q. 강좌 내용을 우리 학교에 맞게 고치고 싶습니다.**
A. `lessons/chNN.js` 파일을 편집하면 됩니다. 문서 · 예제 · 실습 · 퀴즈 · 슬라이드가
하나의 파일에 들어 있고, 구조는 파일 안의 주석을 참고하세요.
